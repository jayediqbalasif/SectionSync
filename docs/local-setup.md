# Local setup

Run `npm install`, then `npm run dev` from this folder.

Open http://localhost:3000/#/planner . Routine is at http://localhost:3000/#/routine .

Use localhost consistently for this workspace; 127.0.0.1 has separate browser storage and may retain the earlier experimental app's offline cache.

Checks: `npm test`, `npm run lint`, and `npm run build`.

The original ZIP remains untouched. The original export is at `backups/original/course-section-planner.zip`; earlier code is preserved under `backups/`.
